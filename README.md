# canteiro-midia

Imagens do conteúdo dos clientes do Canteiro (Venda na Obra): stories e carrosséis que eles
publicam no próprio Instagram. Público de propósito, para o app mostrar e o cliente salvar;
os caminhos não levam nome de cliente. Dados de cadastro nunca ficam aqui.

Também roda o agendador dos avisos de horário (`.github/workflows/avisos.yml`), porque repo
público não gasta minutos do GitHub Actions. Os logs são públicos: o script só imprime contagens.
